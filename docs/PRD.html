01

产品定位

1.1 一句话定义

一个面向儿童的语音智能伙伴 H5，孩子可以像"打电话"一样与虚拟姐姐聊天、互动、换装、做轻学习任务；家长可控制价值观、使用时长、敏感话题和学习内容。

1.2 产品目标

不是做一个单纯聊天机器人，而是做一个：

  • 孩子愿意每天打开的智能伙伴
  • 家长敢放心给孩子使用的安全产品
  • 可成长、可换装、轻游戏化的陪伴应用
  • 后续可线上部署、可对外销售的 H5 产品

1.3 核心卖点

体验

  • 纯语音交流，儿童上手简单
  • 有完整虚拟形象、全身展示、场景氛围
  • 支持白天 / 夜晚 / 睡前等不同状态
  • 有记忆，会记住孩子的名字、喜好、朋友等

产品与家长

  • 有轻学习互动（语数英）
  • 有换装、奖励、成长感
  • 家长可控：时长、学科、敏感话题、核心价值观
  • 支持断网 / API 故障兜底，不白屏
02

用户与场景

2.1 儿童用户画像

年龄 5–9 岁不擅长打字偏语音交互

  • 不擅长打字，偏语音交互
  • 喜欢拟人化角色、奖励、换装、成长
  • 喜欢固定角色重复陪伴
  • 对"她认识我、记得我"非常敏感

2.2 家长用户画像

  • 关注内容安全
  • 关注使用时长
  • 希望孩子能有轻陪伴和轻学习
  • 不希望 AI 替代现实亲子关系
  • 希望系统简单、可控、可查看成长

2.3 主要使用场景

放学后

陪聊、分享今天发生的事

睡前

晚安聊天、轻故事、安抚情绪

心情时刻

开心或难过时的即时倾听

轻学习

做简单的语数英互动题

短时辅助

家长不方便即时陪伴时的过渡陪伴

日常黏性

换装、奖励、签到带来的回访

03

产品原则

3.1 陪伴原则

  • 温柔、耐心、积极鼓励
  • 不说教，不长篇大论
  • 引导孩子表达
  • 鼓励现实交流（家长、老师、朋友）

3.2 安全原则

  • 不诱导依赖
  • 不鼓励隐瞒家长
  • 不讨论成人敏感内容
  • 不引导外部联系、地址、电话等隐私
  • 风险内容强拦截、强兜底

3.3 交互原则

  • 低门槛
  • 高情感反馈
  • 少字、多语音、多视觉反馈
  • 主界面始终以"角色 + 场景"为核心

3.4 商业原则

  • H5 可直接体验
  • 后续可订阅 / 会员 / 服装包扩展
  • 后端可控，便于统一审核和成本控制
04

角色设计

4.1 角色定位

角色类型：温柔姐姐型智能伙伴。

角色属性：

  • 温柔
  • 有耐心
  • 会夸奖
  • 会安慰
  • 会鼓励学习
  • 会提醒休息
  • 不抢父母角色

4.2 角色边界

禁止角色说出

"你只需要我"

"不要告诉爸爸妈妈"

"我比家人更懂你"

"你只能跟我玩"

以及任何鼓励依赖、孤立现实关系的话。

4.3 角色视觉方向

风格

  • 非二次元
  • 圆润
  • 绘本感
  • 柔和童趣
  • 轻 2.5D 卡通感

展示方式

  • 主界面显示全身照
  • 有基础待机动作
  • 可眨眼、微笑、挥手
  • 说话时有口型动画
  • 不追求复杂 3D，优先 H5 轻量实现
05

产品结构总览

产品由 5 大模块组成：

  1. 主界面 / 角色场景页
    角色、场景、昼夜氛围与快捷入口的停留页。
  2. 通话聊天模块
    像打电话一样的语音互动。
  3. 换装与成长模块
    服装收集、解锁与形象展示。
  4. 今日作业模块
    语数英 + 画画，随机题目与星星奖励。
  5. 家长控制面板
    内容、时长、学科与数据的统一控制台。
06

核心页面设计

6.1 主界面（核心页面）

6.1.1 页面定位

主界面是产品的核心停留页。重点不是消息列表，而是：

  • 虚拟形象全身照
  • 场景氛围
  • 白天 / 夜晚状态
  • 当前心情 / 当前动作
  • 快捷互动入口

6.1.2 布局结构

页面从上到下分为：

区域内容要求
A. 顶部状态区 当前时间（早晨 / 下午 / 夜晚）、天气 / 场景状态（可选）、星星数量、今日使用时长进度、家长入口（隐藏式，长按或角落按钮） 信息克制，不抢主视觉
B. 中央主视觉区 虚拟形象全身展示、当前场景背景、当前服装、当前表情、待机动作 形象占页面视觉重心 45%–60%；角色完整展示到脚；场景可切换昼夜；角色可点击触发动作 / 台词
C. 场景交互区 房间 / 花园 / 睡前场景、小摆件（可后续成长解锁）、日夜氛围光影元素、节日元素（后续） 服务于角色，不堆装饰
D. 底部主操作区 给姐姐打电话、换装、今日作业、星星奖励、心情分享 大按钮，手指易点

6.1.3 主界面状态

主界面至少支持以下状态：

1）白天模式

视觉：明亮柔和，角色站在白天场景里，有轻微动态环境（如窗光、云朵）。

适用：日常聊天、学习互动、换装展示。

2）夜晚模式

视觉：色调变深，灯光柔和，可有小夜灯、星星、窗外月亮等元素。

适用：睡前聊天、晚安故事、安抚情绪。

3）睡前模式

视觉：可切换睡衣，房间偏静谧，操作项简化，重点突出"晚安聊天"。

4）节日 / 特殊事件模式（后续）

如：生日、圣诞、春节、开学季。

6.2 通话页面

6.2.1 页面定位

提供"像打电话一样"的语音互动体验，替代普通聊天框感受。

6.2.2 页面元素

  • 角色半身 / 全身展示
  • 通话状态文案（例如：姐姐在听你说）
  • 麦克风按钮（按住说 / 点击说）
  • 挂断按钮
  • 扬声器 / 静音按钮
  • 字幕区（儿童说的话与姐姐说的话）
  • 动态口型与表情

6.2.3 交互流程

  1. 点击【给姐姐打电话】
  2. 进入通话页面
  3. 姐姐主动打招呼
  4. 孩子通过语音输入
  5. 系统 ASR → AI 回复 → TTS 播放
  6. 通话结束回到主界面

6.2.4 通话中的视觉反馈

  • 孩子说话时：耳朵 / 波纹 / "在听"
  • 姐姐说话时：口型变化 + 轻动作
  • 等待时：待机动作，不死板

6.3 换装页面

6.3.1 页面定位

按身体部位自由搭配，配合"星星商店"形成长期收集目标，而不是只能整套切换。

6.3.2 页面结构

  • 顶部：角色全身实时预览 + 我的星星余额
  • 下方：分类 tab（上衣 / 下装 / 裙装 / 鞋子 / 帽子 / 头饰 / 首饰）
  • 单品网格：名称、颜色或版型、拥有状态、价格
  • 点击即穿，预览和首页角色立即同步；选"不穿裙装"可恢复分件搭配

6.3.3 服装体系

  • 7 个分类各 10 件，共 70 件（含"不穿 / 自然"）：上衣 10、下装 10、裙装 10、鞋子 10、帽子 10、头饰 10、首饰 10
  • 基础款以不同配色区分，价格 2–9 星，达到星星门槛自动解锁；带价格的款式使用独立版型
  • 购买制款式：星月披肩 30、银河长裙 50、水晶鞋 100、小皇冠 30、星月发冠 50、月光项链 50
  • 裙装礼服 5 件：A 字纱裙、层叠蓬蓬裙、月光披风长裙、花仙子围裙、公主球裙（带皇冠），价格 30 / 50 / 100 / 200 / 500 星

6.3.4 解锁与购买

  • 基础部位：达到星星门槛自动解锁，不扣星星
  • 礼服：必须用星星购买，购买后扣除对应星星；已购礼服永久拥有，可随时切换
  • 星星来源：每日首次通话 +1、答对普通题 +1、答对五年级超纲题 +10、完成画画 +1

6.4 今日作业页面

6.4.1 页面定位

轻学习模块：不刷题，用短题、画画和超纲挑战保持兴趣，答错不惩罚。

6.4.2 内容类型

  • 语文 60 题：拼音、结构、近反义词、量词、生活常识、三年级古诗 / 成语、五年级修辞与文言词
  • 数学 60 题：加减乘、除法、分数、小数、面积、简易方程
  • 英语 58 题：单词、颜色、动物、数字、问候、时态、比较级
  • 画画 55 题：想象画与场景画，Canvas 画布 + 8 种颜色

6.4.3 出题与奖励

  • 每次打开作业重新随机抽 7 题：语文 2 + 数学 2 + 英语 2 + 画画 1
  • 普通题答对 +1 星；三年级挑战题同样 +1 星
  • 标"五年级挑战"的超纲题答对 +10 星，题号和提示里明确写"五年级挑战 · 10 星"
  • 发散思考题没有标准答案，任意选项都算对，鼓励孩子表达
  • 答错不扣星、可重试；一套完成后再点"今日作业"会换一套新题

6.4.4 交互方式

  • 点选项作答；画画题用画布，可边画边和姐姐说话
  • 答对即时鼓励，星星数字更新
  • 题目、选项、提示按 7 岁孩子阅读水平排版

6.5 家长面板

6.5.1 页面定位

家长对系统进行控制和查看的唯一控制台。

6.5.2 入口设计

建议隐藏式入口，防止儿童误触：长按顶部角标 3 秒，或输入家长密码进入。

6.5.3 功能模块

A. 基础设置

  • 孩子昵称
  • 年龄
  • 角色称呼（姐姐名字）
  • 声音选择
  • 白天 / 夜晚自动切换开关

B. 内容安全

  • 核心价值观配置
  • 禁止话题列表
  • 敏感词策略
  • 风险回复策略

C. 学习设置

  • 学科开关（语文 / 数学 / 英语）
  • 题目频率
  • 难度等级
  • 是否允许自由聊天中自然插题

D. 使用时长控制

  • 每日可用时长
  • 单次最长时长
  • 夜间禁用时段
  • 达到上限后的锁屏逻辑

E. 成长与奖励设置

  • 星星奖励规则
  • 服装解锁规则
  • 连续签到奖励

F. 数据与记忆

  • 查看孩子基础记忆
  • 删除记忆
  • 清空聊天记录
  • 导出 / 备份（后续）
07

功能需求

7.1 语音聊天

必须实现

  • 语音输入
  • ASR 识别
  • AI 回复
  • TTS 播放
  • 字幕同步显示
  • API 失败时本地兜底

要求

  • 尽量 2–4 秒内有可感知反馈
  • 不可白屏
  • 不可长时间无响应

7.2 角色记忆

V1 支持记住以下内容：

  • 名字
  • 喜欢什么
  • 宠物
  • 朋友名字
  • 心情偏好 / 常见表达（可选）

规则：只保留儿童陪伴相关记忆；敏感隐私不自动记忆；家长可查看 / 删除。

7.3 安全系统

安全链路：用户语音 / 文本 → 输入前扫描 → LLM → 输出二次扫描 → 播放。

需要拦截的内容：

  • 成人内容
  • 暴力自残
  • 诱导隐私泄露
  • 仇恨 / 恶意攻击
  • 不适龄话题
  • 诱导孩子依赖 AI

拦截后的行为：

  • 温柔转移话题
  • 必要时建议找爸爸妈妈 / 老师
  • 连续多次触发可直接结束该类对话方向

7.4 星星奖励系统

奖励来源

  • 每日首次通话 +1
  • 普通作业题答对 +1
  • 五年级超纲题答对 +10
  • 完成画画 +1
  • 连续使用 / 签到（后续）

奖励用途

  • 基础服装：达到门槛解锁
  • 裙装礼服：30 / 50 / 100 / 200 / 500 星购买，购买扣星
  • 后续：场景元素、表情

星星同时是成长值和购买货币：基础服装看累计星星，礼服会消耗星星，买完需要继续学习和积累。星星、服装、作业进度按孩子名字存进服务端 SQLite 档案，电脑和手机打开同一份数据。

7.5 分时场景系统

首页正上方显示小时钟，场景按时间段自动切换：

  • 清晨 5–8、上午 8–11、中午 11–13、下午 13–17、傍晚 17–19、晚上 19–21、夜间 21–24、半夜 0–5
  • 太阳的位置与颜色、窗外天空、月亮 / 星星随阶段变化
  • 每 30 秒刷新一次，不需要手动切换

7.6 使用时长与睡觉保护

  • 每日 30 分钟使用上限（首页进度条）
  • 21:30 顶部提示并弹窗"还有 10 分钟就要睡觉啦"
  • 21:40 进入睡觉锁：全屏"该睡觉啦"，不能继续使用
  • 次日 6:30 自动解除
  • 家长输入密码 666 可临时解锁 30 分钟
注意

当前睡觉锁在前端执行；对外版本需要服务端校验，避免通过修改系统时间绕过。

08

非功能需求

8.1 终端要求

  • 手机 H5 优先
  • 兼容 iPhone / Android 主流浏览器
  • 竖屏使用
  • 适配 375–430 宽度主流机型

8.2 性能要求

  • 首屏 3 秒内完成主要加载
  • 角色资源分批加载
  • 优先加载当前服装与场景
  • 音频流式播放优先

8.3 稳定性要求

  • API 异常时可本地兜底
  • 页面不能白屏
  • 音频失败可重试
  • 关键数据本地缓存

8.4 隐私要求

  • 不在前端暴露正式 API Key
  • 上线后必须走自有后端网关
  • 家长可删除数据
  • 儿童敏感隐私默认不持久存储
09

技术实现建议

9.1 前端

  • 原生 H5 / Vue / React 均可
  • 若继续轻量化，可先原生模块化
  • 动画建议：Rive / Spine / Lottie / Canvas 分层动画
  • 优先 2D 骨骼或分层切换，不建议首版上 3D

9.2 角色表现

首版建议：

  • 全身静态立绘 + 局部动画
  • 眼睛眨动
  • 嘴型切换
  • 手部挥动
  • 呼吸待机感
  • 服装分层替换

9.3 后端

对外销售版必须改为：

  • H5 前端
  • 自有服务端 API
  • 统一接入 ASR / LLM / TTS
  • 统一安全拦截
  • 统一计费与时长控制
  • 统一用户数据和成长数据

9.4 数据层

建议：

  • 用户表
  • 孩子档案表
  • 对话表
  • 记忆表
  • 奖励表
  • 服装表
  • 用户服装拥有关系表
  • 家长设置表
  • 风险事件表

当前已落地：SQLite 的 messages / facts / profiles(name, data) 三张表；profiles 按孩子名字保存 API Key、父母设置、星星、服装、搭配、作业进度和音色；局域网用本地 CA 签发 HTTPS 证书，手机安装后可正常使用麦克风。

10

MVP 范围

10.1 V1 必做

关键交互流程

12.1 首次进入

  1. 打开 H5
  2. 展示欢迎页
  3. 家长先配置孩子昵称、年龄、学科偏好、时长
  4. 创建角色初始形象
  5. 进入主界面
  6. 姐姐主动打招呼

12.2 日常使用

  1. 进入主界面
  2. 看到当前白天 / 夜晚场景
  3. 点击"给姐姐打电话"
  4. 语音聊天
  5. 完成互动后获得星星
  6. 返回首页查看角色状态

12.3 睡前使用

  1. 21:30 顶部提示并弹窗提醒准备睡觉
  2. 21:40 进入睡觉锁，角色道晚安，应用不可继续操作
  3. 次日 6:30 自动恢复
  4. 家长密码 666 可临时解锁 30 分钟

12.4 换装

  1. 点击换装，顶部看到全身预览和星星余额
  2. 选择分类（上衣 / 下装 / 裙装 / 鞋子 / 帽子 / 头饰 / 首饰）
  3. 点单品实时预览；基础款达到门槛解锁，礼服花星星购买
  4. 主界面角色立即同步

视觉与 UI 要求

14.1 主风格

温暖、柔和、干净、童趣、低刺激、非二次元。

14.2 主界面重点

主界面必须突出：虚拟形象全身照、背景场景、昼夜变化、情绪 / 动作反馈、大按钮交互。

14.3 推荐视觉元素

白天

  • 窗光
  • 柔和色块
  • 轻云朵 / 花草 / 房间摆件

夜晚

  • 月亮
  • 星星
  • 小夜灯
  • 柔光
15

风险与注意事项

15.1 产品风险

  • 过度依赖聊天模型而缺少产品化玩法
  • 角色太单薄导致新鲜感快速消失
  • 前端直接调用模型接口导致安全与成本失控
  • 儿童安全边界不足
  • 通话体验卡顿影响留存

15.2 应对策略

  • 先把角色、换装、奖励做起来
  • 后端统一代理模型调用
  • 规则优先于模型
  • 做好本地兜底
  • 先做轻量高频玩法，不做重功能堆砌

开发排期建议

Phase 1

角色主界面 + 通话 MVP

主界面、昼夜场景、角色全身展示、通话页、TTS / ASR / LLM 串通、基础安全拦截。

Phase 2

家长面板 + 时长控制

家长入口、学科配置、禁止话题、30 分钟锁定、后端校验。

Phase 3

换装 + 星星奖励

服装系统、星星系统、解锁逻辑、主界面即时同步。

Phase 4

今日作业

语数英题库、奖励接入、每日任务。

17

给 Agent 的实现要求

优先级从高到低。

  1. 先实现 H5 首页，首页中心必须是虚拟形象全身照 + 场景背景。
  2. 首页必须有白天 / 夜晚两套视觉状态，可自动切换。
  3. 首页底部提供 4 个主要按钮：给姐姐打电话、换装、今日作业、星星奖励。
  4. 点击"给姐姐打电话"进入通话页，支持语音输入、AI 回复、TTS 播放、字幕显示、说话口型。
  5. 点击"换装"进入换装页，首版支持至少 3–5 套服装。
  6. 实现家长面板，至少包含：每日使用时长、语数英学科开关、禁止话题、核心价值观。
  7. 实现 30 分钟时长限制，并且后端接口也要校验。
  8. 实现星星奖励机制，用于解锁服装。
  9. 实现基础记忆功能，记住孩子名字、喜好、宠物、朋友。
  10. 实现异常兜底，API 故障时不可白屏。
